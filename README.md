# Projeto-Planeta

Projeto web simples com tema de planeta, criado para praticar HTML, CSS, organizacao de arquivos e composicao visual de uma pagina estatica.

## Conteudo

- Pagina `index.html`.
- Estilos em CSS.
- Imagem principal do projeto.
- Estrutura de landing page estatica.

## Tecnologias

- HTML5
- CSS3
- Git e GitHub

## Como visualizar

Acesse pelo GitHub Pages:

https://matheusgdqueiroz-del.github.io/Projeto-Planeta/

Ou baixe o repositorio e abra o arquivo `index.html` no navegador.
